2
Project Background
[Action: Click Next Slide]

"PinjamGeng is a responsive web application tailored specifically for UPTM clubs and societies, built using PHP, MySQL, and Tailwind CSS. It allows student committees to browse equipment, check live stock availability, and submit loan requests online 24/7. This system replaces slow paper logbooks, prevents booking clashes, and ensures smooth return accountability across campus."

3
Problem Statements
[Action: Click Next Slide, gesture to points 1 and 2]

"We identified two main problems at UPTM:
First, the current manual and uncentralised booking process makes it difficult to check live stock, causing booking clashes, missing records, and slow approvals.
Second, users struggle to choose the right equipment for different events, and existing systems do not offer convenient event-based packages."

4
Project Objectives
[Action: Click Next Slide]

"To solve these issues, two objectives were set for our 12-week development:
First, to develop a web-based booking and inventory system for users to check stock, apply, and track loans, while admins manage records and approvals.
Second, to implement event-based equipment packages for at least four event types: seminars, workshops, meetings, and photography events.
Both objectives were successfully achieved."

5
Agile Methodology
[Action: Click Next Slide, point to Agile circular wheel]

"We used the Agile Scrum methodology, broken into five 2-week sprints: Sprint 1 for architecture and database design, Sprint 2 for authentication and inventory CRUD, Sprint 3 for the booking wizard and conflict algorithm, Sprint 4 for return desk and damage calculation, and Sprint 5 for live cloud deployment and UAT. This allowed continuous milestone reviews with Madam Jihadah."

6
Unit Testing
[Action: Click Next Slide, point to table]

"For Unit Testing, we tested five critical backend functions—including Bcrypt security, dynamic stock subtraction, date validation, and defect fine mathematics. All test cases from UT01 to UT05 passed 100% with zero errors."

7
Integration Testing
[Action: Click Next Slide]

"For Integration Testing, we verified data flow between modules—such as booking form submissions, automatic stock deductions, route security, and equipment returns. All five integration test cases passed 100% successfully."

Core Innovations & Live Cloud
[Action: Click Next Slide]

"PinjamGeng brings three core innovations:
1. Automated Conflict Engine: Blocks overlapping dates automatically.
2. 1-Click Smart Packages: Cuts booking time from 15 minutes to under 60 seconds.
3. Return Damage Engine: Standardized 4-tier grading with automatic fine calculation.
The system is deployed live on the cloud at pinjamgeng.infinityfreeapp.com."
